### Compile risk (nothing here was compiled)

1. `import kyo.kernel.Arrow` was added. `kyo/kernel.scala` in this kernel has `export kernel.Arrow`
   ("Not on main"), so inside `package kyo.kernel` a bare `Arrow` is reachable both from the package
   clause and from `import kyo.*`. Every kernel source that does `import kyo.*` and uses `Arrow`
   (ArrowEffect, Pending, ContextEffect, Loop, Isolate) carries the same explicit import, so this
   follows established practice rather than guessing. `Isolate` is exported from `kyo` on main too
   and main's IsolateTest resolves it through `import kyo.*`, so it needs no explicit import.
2. `Isolate.internal.Contextual.capture { (snapshot: Stack.Snapshot) => snapshot }` relies on the
   implicit lift of a bare `Stack.Snapshot` into `Stack.Snapshot < Any`. `CanLift.derived` should
   apply (`<` is opaque outside its defining file, and `Span[AnyRef]` is neither a singleton nor a
   nested computation), and `Isolate.scala` itself lifts a tuple containing a `Snapshot`, but the
   bare-snapshot lift is not exercised anywhere else in the tree.
3. `snapshot.isEmpty` and `effect.eval.isEmpty` use the `Stack.Snapshot` extension methods.
   `Isolate.scala` calls the same extensions with only `import kyo.kernel.internal.*` in scope, so
   the implicit scope resolves; still, this is the first use of them from a test file.
4. `isolate.run { ... }` replaces `runDetached` in six ported cases. `run[A, S]` has to infer `S`
   from a block whose type is only fixed by the surrounding ascription (`Int < (TestEffect1 &
   NotContextEffect)` and the residual-effect variants). Each has a solution (`S` = the non-context
   half), but the inference is more involved than main's `runDetached`, which took the body directly.
5. `for`/`yield` in the ported cases needs `flatMap` on `<`. It is defined at Pending.scala:91, and
   main's cases used the same shape, so this should be fine.
