**`widen` is forced.** Main's `def widen[A](v: A): A < Any = v` cannot compile here. The lift is a
plain implicit gated by `CanLift` (`internal/Implicits.scala`), and its body is an
`inline scala.compiletime.erasedValue[A] match`. In a non-inline method with an abstract `A` that
match has to reduce immediately and cannot. `Kyo.lift` (`Kyo.scala:35`) survives because it is
itself `inline`, which defers the expansion to the call site where `A` is concrete; making `widen`
inline and routing it through `Kyo.lift` keeps every one of main's four call sites in main's exact
form. The same reasoning forces the local `lift` alias in `"nested"` to be inline. Local inline defs
have precedent in this repo (`kyo-direct/.../internal/Validate.scala:60`,
`kyo-sql-postgres/.../PostgresRowCodec.scala:55`).

**The stack-safety expectations.** `incr` starts from `TestEffect1(n)`, whose handler answers
`n + 1`, then adds 1 per iteration for n iterations, giving `2 * n + 1`. The `"multiple effects"`
variant adds 1 per iteration and a further 1 on each of the `n / 32` iterations that suspend, giving
`n + n / 32`. Both were already in the file and I confirmed the arithmetic rather than trusting it.

**The one place I could not restore main's assertion strength: `"toString"`.** Main pins two exact
strings including `Input(1)` and a source position. Neither is reachable here: `Pending.Suspend`
renders `s"Kyo(${tag.show}, ${site(frame)})"` with no input and no snippet
(`internal/PendingInternal.scala:38-40`), and `map` over a suspension allocates a
`Pending.DeferWith`, so the rendering is `Defer(Kyo(<tag>, <site>), this(<site>), Id)`
(`PendingInternal.scala:21-30`, `Arrow.scala:37,89-93`). I strengthened the pre-existing
`contains`-only checks to pin that whole structure (`startsWith`, the `", Id), this("` seam for the
nested case, `endsWith(", Id)")`), which is the same shape `ArrowTest` uses for `Step` and `Chain`
renderings, but it is still not byte-exact the way main's is. Producing an exact expectation would
mean predicting `Frame.callerName`, `calleeName` and a line:column in a file I am writing, without
being able to run it; I did not want to invent one. This is the single honest gap in the file.

Ordered by how likely I think a failure is.

1. **`KyoTest` `"eval"`, the `typeCheckFailure` message.** I restored main's expected text,
   `"value eval is not a member of Int < KyoTest.this.TestEffect1"`. The `eval` extension has the
   same `extension [A](inline v: A < Any)` shape here (`Pending.scala:386,398`) and `kyo.<` is the
   same alias in both kernels (`kernel.scala`), so the message should be identical, but this is a
   compiler-rendered string I could not observe. If it differs the case fails at run time, not at
   compile time.
2. **`KyoTest` `"toString"`.** The structural expectations above are derived by reading
   `Defer.toString`, `Suspend.toString`, `short` and `Arrow.Transform`. If `map` takes the
   non-deferring branch for a settled receiver the shape would differ, but the receiver here is a
   suspension so `shouldDefer` is true.
3. **`inline def widen` and the local `inline def lift`.** Reasoned from `Implicits.lift`,
   `CanLift` and `Kyo.lift`, with repo precedent for the local inline def. If the local one is
   rejected, the one-line fallback is to delete it and call `widen(TestEffect1(1))` directly.
4. **`LoopTest`'s `import kyo.*`.** Resolution of `Loop`, `Arrow` and `<` between the wildcard
   import and the enclosing `kyo.kernel` package relies on wildcard imports outranking
   package members from other compilation units. Main does the same thing in the same file.
5. **`LoopTest` without `given Frame`.** Every `(using Frame)` site now expands the macro. It is
   exempted from the in-package ban by the `Test.scala` suffix rule, and this is what main does.
6. **`KyoTest extends Test`.** `kyo.Test` mixes in `NonImplicitAssertions`; the file uses only
   `assert`, `fail` and `typeCheckFailure`, no `===` and no matchers.
7. **The dropped `, a => a`** in `KyoForeachTest` and `KyoTest`: `S2` must infer to `Any` from the
   declared `A < S` result. `ArrowEffectMaskTest.scala:20-21` is the same shape.
